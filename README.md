# 论文写作自教课程（academic-paper-writing-course）

> 由四本论文写作方法书蒸馏而成的 AI 可调用 skill：**九关 · 80 个能力卡**，覆盖从「怎么找文献」到「SCI 投稿回复审稿」的论文全生命周期。
> 蒸馏流水线：整书理解 → 五路提取（框架/原则/案例/反例/术语）→ 三重验证（跨域/预测力/独特性）→ RIA++ 能力卡 → 编译交付。

## 这是什么

一个 [CodeBuddy Code](https://www.codebuddy.cn) 格式的 **skill 课程包**。安装后，你用自然语言说写论文相关的任何话，它会：

1. 判断你卡在哪一关（检索 / 选题 / 文献 / 论证 / 结构 / 文风 / 故事 / 过程管理 / 英文写作 / 投稿）；
2. **只加载对应那一张能力卡**（含原文佐证、方法重述、书中案例、触发场景、执行步骤、边界警告）；
3. 按卡内步骤带你完成可检验的产出（如 100 字研究问题陈述、论证树诊断表）。

| 第五关 | 中文文风：透明玻璃、四腔戒除、句子级自查 | 3 | 《写作是门手艺》 |

⭐ 核心卡（critical）：三步提问法、选题四象限、检索六步闭环、检索式构建五步法、论证树、TAIMRDR、英文学术正式性改造、hedging 工具箱、图表形式规范、审稿意见逐条回应、先有后好、克服写作障碍十条 等，共 15 张。

## 安装

```bash
# 方式一：从 zip 解压
unzip academic-paper-writing-course-skill.zip -d <解压目录>

# 方式二：直接复制目录
cp -r dist/academic-paper-writing-course ~/.codebuddy/skills/
```

安装后**新开会话**即可生效。

## 使用示例

| 你说 | 它加载 |
|---|---|
| "我的题目太大了，怎么收窄" | 三步提问法 + 选题四象限 |
| "检索出上万篇文献怎么下手" | 检索式构建五步法 + 查全查准权衡 |
| "导师说我的综述像流水账" | They say/I say 对话模板 + 综述结构化 |
| "审稿人说我的英语不地道" | 英文学术正式性改造 |
| "大修意见 40 条怎么回" | 审稿意见逐条回应与礼貌异议 |
| "写不下去了，deadline 快到了" | 克服写作障碍十条 + 先有后好 |

## 边界与声明

- 本课程只处理**以证据和逻辑说服同行的说理写作**；不适用创意写作、公文文案。
- **不代写整篇论文**、不伪造数据与文献（学术诚信边界写在卡内 B 段）。
- 《文献检索与论文写作》中数据库界面描述已按"策略与决策规则"重写，不含会过时的 UI 点击步骤。
